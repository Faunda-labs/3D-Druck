# 3D-Druck – Website & Projektdateien

Website (Arbeitsname **Schichtwerk**) für unser 3D-Druck-Business.

- `docs/` – statische Website, veröffentlicht über GitHub Pages
  - `index.html` – Startseite (Produkt, Anleitung, Material, Über uns, FAQ)
  - `img/` – Produktbilder (KI-Visualisierungen, gekennzeichnet)

## Vor dem offiziellen Start
- Etsy-Link eintragen (`id="buy"` in `docs/index.html`)
- Impressum, Datenschutz, AGB, Widerruf als eigene Seiten
- Markenname final festlegen
